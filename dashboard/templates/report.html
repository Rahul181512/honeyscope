Automated security report generator

Generates a timestamped report summarising the observation window: executive KPIs, attack timeline charts, top attacker IPs, most attempted credentials, and rule-based defensive recommendations. The HTML file is fully self-contained (Chart.js is embedded) and can be submitted or printed to PDF directly.

Export all events (CSV) Export all events (JSON)

What the report contains

  • Executive summary with key metrics
  • 72-hour attack timeline chart
  • Severity / service / pattern distribution charts
  • Top attacker IPs with worst-severity classification
  • Most attempted usernames & passwords
  • Defensive recommendations derived from observed patterns
  • Ethics & scope statement for academic submission

Suggested viva workflow

  1. Run python run.py and open the Overview page.
  2. Trigger attacks: python scripts/simulate_attacks.py --all.
  3. Show live dashboard updates on the timeline and feed.
  4. Open Events, filter by severity = CRITICAL.
  5. Generate the security report and export the CSV dataset.
